# Sample models

The sample models these tests read (`ReggieTheRat.cpmmodel`, `SkullDog.cpmmodel`,
`Expie_by_Clouddy.cpmproject`, `rainwing-old.cpmproject`) belong to other creators and are not distributed.

To run the sample-based tests, drop `.cpmmodel` / `.cpmproject` files with those names into this directory.
Without them those tests print `skipping: sample <name> not present` and return early.
